# Initial reference applications

The project began with two broad interface and capability references:

- GIMP — the established FOSS raster editor and an important comparison point for Linux-native workflows.
- Krita — a mature Qt-based FOSS painting application and a useful reference for compact layer controls and painting interaction.
- Photopea — a browser-based layered image editor and a useful reference for familiar document and layer interactions.
- VFX Texture Lab — the companion VFX Suite application and the authoritative source for the shared Midnight, Graphite and Daylight palette tokens.

VFX Photo Lab is not intended to clone either application. Its distinguishing direction is a focused nondestructive workflow, editable looks, batch processing and a high-performance image engine shared conceptually with the VFX Suite.
