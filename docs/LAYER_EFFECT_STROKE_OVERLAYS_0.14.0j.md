# 0.14.0j — Stroke and Overlay Effects

0.14.0j activates three more concrete renderers on the persistent Layer Effect (`fx`) architecture: **Stroke**, **Colour Overlay** and **Gradient Overlay**. They remain authored per-layer effects, not Live Filters, and work on eligible Raster, Vector, Text and Smart Layers.

## Stroke

Stroke is generated from the layer's full-precision effective coverage after its own layer mask has shaped the silhouette. It does not rasterise or modify the authoritative layer content.

- **Outside**: dilated coverage minus original coverage; composites behind the source.
- **Inside**: original coverage minus eroded coverage; composites above the source.
- **Centre**: dilated coverage minus eroded coverage around the original edge; composites above the source.

Stroke exposes Colour, Effect Opacity, Blend Mode, Position and Size. Its spatial radius participates in Layer Effect halo propagation, dirty-region fingerprints and the bounded effect-pass cache.

## Colour Overlay

Colour Overlay generates a solid-colour pass constrained by the layer's effective coverage and composites it above the source. It has independent colour, opacity and blend mode and therefore does not rewrite the source pixels.

## Gradient Overlay

Gradient Overlay generates a coverage-constrained gradient pass above the source. It reuses the existing gradient-stop representation/editor and supports:

- Arbitrary ordered colour stops.
- Linear, Smooth or Constant stop interpolation.
- Linear or Radial gradient style.
- Angle for linear gradients.
- Scale from 10–1000%.
- Reverse.
- Independent effect opacity and blend mode.

Gradient coordinates use stable owner content bounds in document space. They are never based on the requested render tile, so separately rendered tiles stitch to the same pixels as a full-region render. Because a distant source/mask edit can move those global bounds and change the gradient in an otherwise-local tile, Gradient Overlay opts into a conservative global owner-identity dirty fingerprint; the other 0.14.0j effects retain local dirty propagation.

## Precision, masks and compositing

All three effects derive from the same mask-aware coverage contract introduced in 0.14.0h/i. 8-bit and 16-bit paths are supported, off-canvas coverage is retained where required, and authoritative hidden RGB remains untouched.

Generated passes remain independent through native WebGPU hierarchy composition. The effect image is generated by the shared exact reference path and may be retained in the existing bounded native resident-texture cache; WebGPU does not substitute a visually different Stroke or gradient implementation.

## Persistence and migration

0.14.0j uses:

- `.vfxphoto` format **25**.
- Embedded Smart document schema **8**.
- Hot/Warm/Cold snapshot format **26**.
- Layer Effect schema **3**.

Schema-1/2 Stroke and Overlay placeholders migrate disabled so loading an older project cannot alter appearance. They receive deterministic 0.14.0j defaults, allowing a user to enable them later without inheriting meaningless old placeholder values such as a zero-width Stroke.

Older project/snapshot envelopes are not allowed to smuggle schema-3 Stroke/Overlay metadata through either top-level layers or embedded Smart Source documents.

## Deferred

**Bevel & Emboss** remains an explicit disabled definition and is implemented in **0.14.0k**.
